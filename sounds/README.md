# Replacement sounds

A WAV file in this folder named after a sound of the game is played in its
place: `AUDXL.wav` for the X-wing's lasers, `PMTH5.wav` for the main theme,
`SPKRED.wav` for "Red Five standing by". The 59 names, the format of the
files and how they play are in [docs/SOUNDS.md](../docs/SOUNDS.md).

The folder is empty: every sound still comes from the board's chips.
